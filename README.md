# 📝 나의 할 일 목록 (To-Do List App)

모던하고 깔끔한 웹 기반의 **할 일 관리(To-Do List) 애플리케이션**입니다.  
사용자의 생산성을 향상시키기 위해 다양하고 편리한 기능과 세련된 글래스모피즘 UI 디자인을 제공합니다.

---

## 🌟 주요 기능

- **📝 할 일 관리 (CRUD)**: 새로운 할 일 추가, 완료 체크 토글, 개별 삭제
- **💾 LocalStorage 자동 저장**: 브라우저를 새로고침하거나 종료 후 다시 접속해도 데이터가 안전하게 영구 유지
- **🚫 중복 방지**: 이미 등록된 할 일을 다시 입력할 경우 중복 알림 메세지 출력
- **📊 실시간 카운터 통계**: 전체 할 일 개수 및 완료된 할 일 개수를 실시간으로 상단 뱃지에 표시
- **🔍 탭 필터링**: `전체`, `진행중`, `완료` 탭을 통해 원하는 상태의 할 일만 골라보기
- **🧹 완료 항목 일괄 삭제**: 완료 처리된 모든 항목을 클릭 한 번으로 일괄 제거
- **🎨 모던 UI 디자인**: 둥근 카드 레이아웃, 소프트 그라데이션 및 반응형 호버 애니메이션

---

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: HTML5, CSS3 (Vanilla CSS), JavaScript (ES6+)
- **Icons & Fonts**: Font Awesome 6, Google Fonts (Outfit, Noto Sans KR)
- **Storage**: Browser LocalStorage API
